Technical implementation

Built to keep working, even when the AI doesn’t

Stack

  • Next.js 15, React 19, TypeScript, Tailwind CSS 4
  • Groq: GPT-OSS 120B and 20B in JSON mode
  • zod validation with automatic repair retry
  • cheerio for page text, dates and official-domain detection
  • Results stream live; no database needed

Reliability

  • Works with no API key in offline keyword mode
  • Any failed AI step falls back to rules, with a warning
  • Rate limits: switches models, then backs off
  • Long pages trimmed to relevant passages: 141 s → 22 s
  • Blocks private addresses and “page not found” pages

Digital Dark Spot

11

Under the hood: Next.js and TypeScript, with Groq’s GPT-OSS models for the language work. Every AI response is validated against a schema and repaired if needed. It’s designed to degrade gracefully: no key, it runs offline with keyword matching; an AI step fails, it falls back to rules and tells you. We cut a full analysis from 141 seconds to about 22 by sending only relevant passages and spreading work across two models.
